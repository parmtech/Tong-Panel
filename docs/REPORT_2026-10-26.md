## 6. Research constraints
- HestiaCP and Virtualmin reference features are not automatically safe or licensable for direct code import. Original code and service adapters with component-specific licence review remain proposed.
- The old File Browser project is archived and warns that no new fixes are shipping; use UI conventions rather than copying an unmaintained server file browser.
- One-command installer can support only specifically tested fresh Linux distros, not every VPS/hosting provider.
- Account/service cloud costs are external even where Tong Panel itself is free.
